# RinkuDa_projects

Monorepo for the farmer registry platform.

| App | Path | Stack |
|-----|------|-------|
| Admin web | `Admin - web/admin-dashboard` | React, Vite, Firebase |
| Mobile | `Mobile/Flutter/farmer_registry_flutter` | Flutter, Firebase |
| Desktop | `DesktopApp/` | Flutter / Electron |
| **API** | `Backend/farmer-registry-api` | **NestJS, MongoDB** |

See `Backend/farmer-registry-api/README.md` for API setup and routes.
